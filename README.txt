Myanmar Mart — Historical Catalog

HOW TO RUN / ဖွင့်သုံးနည်း
1. Extract / Unzip this file to a folder.
2. Open the extracted myanmar-mart-archive-site folder.
3. Double-click index.html. The CSS, JavaScript, logo and product photographs are included locally.
4. If your browser blocks local scripts, run python3 -m http.server 8000 from this folder and visit http://localhost:8000.

The two product photographs are recovered from archived Myanmar Mart image files in the Internet Archive (Wayback Machine):
Logo painting: https://web.archive.org/web/20150804022443im_/http://myanmarmart.com/images/gem_paintings.jpg
Mascot painting: https://web.archive.org/web/20141223111514im_/http://myanmarmart.com/images/17-13_mascot.jpg
The product listing details are from the archived December 2013 catalog. This is a historical recreation, not a live shop.
